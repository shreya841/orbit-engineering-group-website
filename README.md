India's Premier Water Infrastructure, SCADA Telemetry & PLC Automation Company (Bhopal, MP).

## 🚀 Quick Start
```bash
cd C:\Users\Himanshi\.gemini\antigravity\scratch\orbit-engineering-3d
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🎬 How to Add Your Hero Video
1. Drop your video file into the `public/` folder named **`hero-video.mp4`**:
   ```
   public/hero-video.mp4
   ```
2. The website will automatically detect and play your video in the 3D Hero video frame with play/pause, volume/mute, and fullscreen controls.
3. Alternatively, you can change the video URL or fallback in:
   `src/config/siteConfig.js` -> `heroVideo.videoUrl`
